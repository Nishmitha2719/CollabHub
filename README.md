# 🚀 CollabHub – Find Your Team. Build Together.

CollabHub is a collaborative project platform designed to connect students with similar interests, help them discover project opportunities, and build teams to turn their ideas into reality.

Instead of struggling to find teammates with the right skills, students can explore projects, create their own initiatives, apply to join existing teams, and collaborate with like-minded individuals.

## ✨ Features

- **User Authentication:** Secure sign-up and login functionality.
- **Project Discovery:** Explore projects created by other students.
- **Create Projects:** Publish project ideas with descriptions, required skills, and team capacity.
- **Join Projects:** Apply to become a member of projects that match your interests and skills.
- **Team Management:** Manage project members, applications, and team roles.
- **Project Approval:** Admin-based project approval and moderation.
- **Team Capacity Management:** Prevent applications from exceeding the available team slots.
- **User Profiles:** Showcase personal information, skills, and project interests.
- **Admin Dashboard:** Manage platform activities and review project submissions.
- **Project Tracking:** Keep track of team collaboration once a team is formed.

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Nishmitha2719/CollabHub.git
```

### 2. Navigate to the Project

```bash
cd CollabHub
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the root directory and add your Supabase credentials:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 5. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
